# 平台解析器检查清单

## 架构与注册

- [ ] 解析器是 `ParserUID/parsers/<name>/` 包，不在 `parser.py` 增加平台分支。
- [ ] 第三方解析器位于 `data/ParserUID/thirdparty/parsers/<name>/`。
- [ ] `__init__.py` 导出 `PARSER`，且不执行 I/O。
- [ ] 目录名、`config.json.name`、`PARSER.platform.name` 一致。
- [ ] 没有通过修改 `parsers/__init__.py`、全局配置或注册清单添加平台。
- [ ] 关键词在所有内置和第三方解析器中唯一。
- [ ] 重复关键词会拒绝注册并记录两个平台。
- [ ] 注册器不可用时，明确失败原因。

## 匹配与解析

- [ ] 所有链接入口都使用 `@handle(keyword, pattern)`。
- [ ] 关键词能有效缩小候选范围。
- [ ] 正则匹配明确 host/path，不抢占其他平台链接。
- [ ] 每条消息只解析首个命中的链接。
- [ ] 首个命中解析器接受任务后停止传播。
- [ ] 平台之间没有优先级。
- [ ] 配置通过基类读取，没有散落的原始配置访问。
- [ ] `__init__` 不发起网络请求，也不执行长时间阻塞操作。
- [ ] API 请求使用基类注入的异步会话。
- [ ] 访问失败或认证失败转换为 `ParseException` 或其子类。

## 描述与媒体

- [ ] 通过 `send_info()` 发送预览卡片。
- [ ] 卡片只使用结构化 `Description` 数据，不拼 HTML。
- [ ] 描述卡片发出前没有启动最终媒体下载。
- [ ] 最终结果是按发送顺序排列的 `result([...])`。
- [ ] 图片、视频、音频、文件使用明确的公共内容类型。
- [ ] 没有用字符串冒充媒体。
- [ ] 没有发送分组、媒体类型重排或占位媒体。
- [ ] 解析器没有直接构造 GsCore 消息段。
- [ ] 解析器没有直接调用 `bot.send()`。
- [ ] 合并转发和文字回退由发送层处理。

## 配置

- [ ] 默认值和字段定义位于解析器包内 `config.json`。
- [ ] 用户值位于 `data/ParserUID/parser_config/<name>.json`。
- [ ] 所有解析器的 `default_enabled` 为 `false`。
- [ ] 修改默认值没有覆盖已有用户配置中的 `enabled`。
- [ ] 敏感字段标记 `secret: true`，配置列表接口不回显原值。
- [ ] 解析器启停和皮肤选择只在网页配置页。
- [ ] 其他阈值位于插件普通配置。
- [ ] 没有为解析器字段另设第二个启用来源。

## 第三方解析器

- [ ] 只扫描 `data/ParserUID/thirdparty/parsers/` 的直接子目录。
- [ ] 不把第三方目录加入全局 `sys.path`。
- [ ] 只接受受限目录内的相对路径。
- [ ] 与内置解析器同名时拒绝注册。
- [ ] 第三方解析器默认不启用。
- [ ] 不要求签名、版本校验或自动更新。
- [ ] 导入失败只跳过该解析器，不影响其他解析器。

## 渲染

- [ ] 卡片只经 `ParserUID/utils/render/render.py` 渲染。
- [ ] 解析器不直接导入皮肤包内部模块。
- [ ] 皮肤包不访问任意路径，不引用外部脚本。
- [ ] 合并转发失败回退为文字，不生成图文回退卡片。

## 网络、下载与安全

- [ ] 网络 I/O 全异步，超时和重试有限。
- [ ] 通用下载经过 `ParserUID/utils/downloader.py`。
- [ ] 下载器复用框架 `download_file.download`。
- [ ] 阻塞的同步库调用经过 `asyncio.to_thread()`。
- [ ] Cookie、Token、缓存和临时文件只写数据目录。
- [ ] 日志不含凭证、签名、完整敏感 URL 或原始响应。
- [ ] 用户错误信息不暴露堆栈、路径或内部异常对象。
- [ ] 新增会话、任务和调度器都有释放路径。

## 代码规范

- [ ] 函数和方法都有可追踪的类型注解。
- [ ] 没有 `Any`、`cast()`、`type: ignore`。
- [ ] 没有用 `getattr` 或 `dict.get` 默认值兜底。
- [ ] 没有用 `try/except` 吞掉未知异常。
- [ ] 平台响应模型已显式定义并经过类型守卫。
- [ ] import 直达具体模块，没有聚合转发业务函数。
- [ ] 注释不超过两行，每行不超过 88 个字符。

## 测试与验证

- [ ] 网络测试使用模拟会话，不依赖真实 Cookie 或线上站点。
- [ ] 注册测试证明解析器可被发现、身份一致、关键词可匹配。
- [ ] 配置测试证明用户配置可创建、校验和启停。
- [ ] 测试证明解析器默认不启用。
- [ ] 测试证明禁用解析器不进入匹配快照。
- [ ] 修改 `config.json` 后已校验 JSON。
- [ ] `python -m ruff check ParserUID` 通过。
- [ ] `python -m ruff format --check ParserUID` 通过。
- [ ] `python -m basedpyright ParserUID` 通过。
